# English Quest 🇬🇧

**English Quest** - интерактивный тренажёр для практики английского языка через диалоги и ситуации из реальной жизни.

## Возможности

- **Выбор уровня английского:** Beginner, Intermediate или Advanced.
- **Выбор темы:** можно выбрать направление, в рамках которого хочется практиковать английский.
- **Различные жизненные сценарии:** например, путешествия, заселение в отель и другие повседневные ситуации.
- **Практика в формате диалога:** пользователь отвечает на вопросы, которые могут встретиться в реальной жизни, и тренирует навыки общения на английском языке.

## Цель проекта

Сделать практику английского языка более интересной и приближенной к реальному общению, чтобы пользователь мог увереннее чувствовать себя в повседневных ситуациях.
